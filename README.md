# Laghu

Laghu is a C++23 server project.

This repository is at its initial source-tree bootstrap. It intentionally has no build system or runnable server yet.

## Repository layout

- \`src/\`: first-party implementation boundaries.
- \`tests/\`: subsystem-mirrored tests.
- \`fuzz/\` and \`bench/\`: future fuzzing and benchmark work.
- \`packaging/\`, \`examples/\`, and \`docs/normative/\`: future delivery,
  examples, and normative documentation.
