# Code of Conduct

Laghu follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful, give constructive feedback, accept responsibility, and focus on what is best for the community.

Unacceptable behavior includes harassment, discriminatory or sexualized language, trolling, personal attacks, and publishing another person's private information without permission.

Report conduct concerns to <admin@codevedas.com>. Maintainers will review reports promptly, preserve reporter privacy, and apply proportionate corrective action up to permanent exclusion from project spaces.
