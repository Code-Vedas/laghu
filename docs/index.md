# Laghu

Laghu optimizes delivery through native NGINX and Apache integrations or a mature standalone server. Every surface shares policy, cache, worker, security, and fail-open behavior.

Choose NGINX or Apache when native server integration is the operating boundary. Choose standalone when an independently scaled service, YAML configuration, and modern delivery features fit the deployment boundary.

Start with [Operations](/operations/), then select [NGINX](/ngx-laghu/), [Apache](/mod-laghu/), or [standalone](/laghu-server/). Repository contributors should use the [developer guide](/developer-guide/).
