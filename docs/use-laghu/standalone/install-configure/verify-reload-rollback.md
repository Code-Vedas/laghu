# Verify, reload, and rollback

Validate the intended YAML with `laghu --config /etc/laghu/laghu.yaml`, then use `laghu reload --config /etc/laghu/laghu.yaml`. Restore the saved YAML if readiness fails.

## Check

Follow the next page only after this step has completed without an installation or configuration error.
