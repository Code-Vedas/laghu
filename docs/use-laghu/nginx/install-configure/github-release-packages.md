# GitHub Release packages

Download the signed `ngx-laghu` asset matching the installed NGINX ABI and architecture from the Laghu release. Install with the host package manager, verify its checksum/signature, then continue with module loading.

## Check

Follow the next page only after this step has completed without an installation or configuration error.
