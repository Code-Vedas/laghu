# Homebrew

Install from the Code-Vedas tap with `brew tap Code-Vedas/tap` and `brew install ngx-laghu`. Use the Homebrew NGINX configuration directory when loading the module.

## Check

Follow the next page only after this step has completed without an installation or configuration error.
