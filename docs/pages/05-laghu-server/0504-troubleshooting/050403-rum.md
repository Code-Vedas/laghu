# Laghu Server RUM, Redis, and Instrumentation

Confirm instrumentation injection through `laghu explain`, then inspect CSP eligibility, browser sampling, beacon route status, origin/MIME validation, catalog membership, rate limits, and aggregate expiry.

For Redis/Valkey failures, verify hiredis loading, remote DNS/TCP, `rediss://` CA and hostname, credentials, ACL access to scripts and keys, database number, prefix, timeout, and durable backend health.
Atomic Lua errors retain the same pending batch for retry; repeated contract/type failures require operator inspection of the configured namespace.

Memory remains the serving path during backend maintenance.
Use synchronization lag, pending bytes, snapshot age, template readiness, and decision generation to confirm recovery without reading or editing raw backend values.
