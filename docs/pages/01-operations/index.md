# Operations

Laghu has one policy and runtime model across NGINX, Apache, and standalone. Select the adapter that fits the hosting boundary; configure queues, cache paths, workers, authenticated administration, and observability consistently.

Run the selected adapter with its deployment guide, start only the workers enabled by its configuration, and use readiness plus protected statistics for health checks. A missing worker or invalid derived artifact preserves the origin response.

Use [NGINX](/ngx-laghu/), [Apache](/mod-laghu/), or [standalone](/laghu-server/) for adapter setup. Contributors should use the [developer guide](/developer-guide/).
