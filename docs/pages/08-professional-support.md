# Professional Support

Use [GitHub issues](https://github.com/Code-Vedas/laghu/issues) for reproducible bugs, feature proposals, and documentation defects.

Codevedas offers optional professional help for architecture reviews, matched module builds, deployment planning, performance investigations, and production incidents. Contact <admin@codevedas.com> with the server product and operating system, Laghu revision, observed behavior, validation output, and the outcome you need.

Professional support is optional. Laghu remains complete MIT-licensed software without accounts, license keys, paid tiers, hosted-service dependencies, nag screens, or restricted community functionality.
