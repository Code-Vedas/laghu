# Support

Use GitHub issues for reproducible bugs, feature proposals, and documentation problems. Use GitHub Discussions for public implementation and deployment questions when discussions are enabled for the repository.

## Professional Support

Codevedas offers optional professional help for architecture reviews, module builds, migration planning, performance investigation, and production incidents. Contact <admin@codevedas.com> with the server details and the outcome you need.

Laghu is free, complete open-source software under the MIT license. NGINX and Apache capabilities do not require an account, license key, paid tier, hosted service, or professional-support agreement.
