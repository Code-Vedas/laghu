# Support

Use GitHub issues for reproducible bugs, feature proposals, and documentation
problems. Use GitHub Discussions for public implementation and deployment
questions when discussions are enabled for the repository.

## Professional Support

Codevedas offers optional professional help for architecture reviews, module
builds, migration planning, performance investigation, and production
incidents. Contact <admin@codevedas.com> with the NGINX version, deployment
shape, and the outcome you need.

Laghu is complete open-source software under the MIT license. Professional
support does not unlock separate product features.
